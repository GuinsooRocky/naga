# naga 产品需求

## 一句话目标

一个只给自己用的安卓 app，能给吉他调音，能打节拍，没有会员、广告和登录。

## 使用场景

- 拿起吉他先调音：打开 app，逐根拨弦，看着屏幕拧弦钮，六根都变绿就开始弹。
- 练琴时打拍子：设好速度，点开始，手机放一边，锁屏也继续响。

## 整体结构

底部两个标签：**调音**、**节拍**。打开 app 默认进调音页。全程深色界面，app 在前台时屏幕不自动熄灭。

## 一、调音器

### 功能

1. **自动识弦**：拨任意一根弦，自动判断是哪根，不用手动选。
2. **手动锁弦**：点某根弦可以锁定只调这一根，再点一次回到自动。弦断了重新上弦、音差得很远时用。
3. **调弦方案**：只做标准调弦，6 弦到 1 弦依次是 E A D G B E。
4. **基准音**：固定 A4 = 440Hz。

### 界面

- 中间是一条刻度，正中是「准」，指针偏左表示偏低，偏右表示偏高。
- 刻度上方用大字显示当前这根弦的音名（如 E、A）。
- 刻度下方一行小字提示「拧紧一点」或「放松一点」。
- 偏差进入 ±3 音分时指针和音名变绿；之后只要弦还在响、偏差没超过 ±6 音分，就一直保持绿色，不会一闪一闪。
- 屏幕下方排六个圆点代表六根弦，当前弦高亮，本次已经调准过的打勾。
- 没有声音时指针归位变灰，不显示读数。

### 标准

| 项目 | 标准 |
|---|---|
| 准确度 | 误差不超过 ±1 音分（一个半音是 100 音分） |
| 判定为「准」 | 偏差在 ±3 音分以内 |
| 能识别的范围 | 6 弦空弦（82Hz）往下松很多也能认出来（低到约 65Hz），往上覆盖 1 弦空弦（330Hz）并留余量 |
| 反应速度 | 拨弦后 0.3 秒内出读数 |
| 稳定性 | 一次拨弦过程中指针不乱跳，不把低音弦认成高八度 |
| 抗干扰 | 普通房间里有人说话时不误触发 |

## 二、节拍器

### 功能

1. **速度**：30 到 240 BPM。可以拖动调，也可以点加减号一格一格调。
2. **敲击测速**：连续点几下「敲击」按钮，自动算出速度。
3. **拍号**：2/4、3/4、4/4、6/8。
4. **重音**：每小节第一拍声音不同，可以关掉。
5. **后台播放**：锁屏或切到别的 app 继续响，通知栏有暂停按钮。
6. **记住设置**：下次打开还是上次的速度和拍号。

### 界面

- 正中大字显示当前 BPM。
- 上方一排圆点表示一小节的每一拍，响到哪拍哪个亮，第一拍颜色不同。
- 下方一个大的开始/停止按钮。
- 拍号和敲击测速放在按钮两侧。

### 标准

| 项目 | 标准 |
|---|---|
| 节拍间隔 | 每拍间隔误差不超过 1 毫秒 |
| 长时间稳定 | 连续响 30 分钟不越走越快或越慢 |
| 画面同步 | 圆点亮起和听到声音对得上（用手机扬声器时） |
| 调速 | 播放中改速度，下一拍立即生效，不卡顿不爆音 |

## 不做的事

- 登录、会员、广告、统计上报
- 上架应用商店
- 其他乐器、半音阶模式、标准调弦以外的调弦方案（如 Drop D）、基准音可调
- 节拍细分（八分、三连音）、渐快练习、歌单
- 浅色界面、多语言、平板适配
- 蓝牙耳机的延迟补偿

## 交付方式

打包成安装包，用数据线装到手机上。支持安卓 8 及以上。

调音器和节拍器一起交付。

## 验收

**调音器**

1. 打开 app，允许使用麦克风。
2. 依次拨六根弦，每根都能显示正确的音名。
3. 故意把一根弦拧松，指针偏左并提示「拧紧一点」；拧回去，指针回中变绿。
4. 用另一个调音器对照，两边判定「准」的位置一致。
5. 不弹琴、旁边正常说话，指针不乱动。

**节拍器**

1. 设 120 BPM、4/4，点开始，听到「重、轻、轻、轻」循环，圆点跟着亮。
2. 锁屏，声音继续；从通知栏能暂停。
3. 连点「敲击」四下，显示的速度和手点的速度差不多。
4. 播放中把速度拖到 200，立刻变快，没有卡顿。
5. 关掉 app 再打开，速度和拍号还是上次的。
